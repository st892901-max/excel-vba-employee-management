# Excel VBA Employee Management System

An Excel portfolio project with 8 VBA features for managing employee records and creating reports.

## Features

1. Add employees with automatically generated IDs.
2. Delete employees after confirmation.
3. Search employee records.
4. Split full names into first and last names.
5. Extract employees whose names contain "Thapa".
6. Generate a summary of employee counts by last name.
7. Create a dashboard with a PivotTable and pie chart.
8. Open an email draft for sharing the workbook. Attach the file and send manually.

## Tools Used

- Microsoft Excel for Mac
- VBA
- PivotTables and charts
- Worksheet buttons

## How to Use

1. Download Employee_Practice_Fx.xlsm.
2. Open it in desktop Microsoft Excel.
3. Enable macros if you trust the file.
4. Open Sheet1 and use the worksheet buttons.
5. Run SplitNames before CreateDashboard to populate the last-name column.

VBA macros require desktop Excel; they do not run in GitHub's preview.
